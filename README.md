# Tugass_DailyBoard_Gentaa

Pada DailyBoard ini memiliki beberapa fitur untuk membantu pengguna mengatur kegiatan sehari-hari. Yang pertama ada fitur Dark Mode yang digunakan untuk mengubah tampilan menjadi mode gelap atau terang. Terdapat juga status pesan yang menampilkan informasi bahwa data berhasil dimuat. Terus Pada bagian Daftar Tugas, pengguna dapat menambahkan tugas baru, mencari tugas, serta memfilter tugas berdasarkan status Semua, Selesai, atau Belum Selesai. Setiap tugas juga dapat dihapus menggunakan tombol Hapus. Dan pengguna juga bisa mengubah urutan tugas dengan fitur drag and drop.

Selain itu, terdapat Fitur Catatan Cepat yang digunakan untuk menambahkan catatan, serta menyediakan tombol Edit dan Hapus untuk mengelola catatan. Dan juga ada Fitur Cek Cuaca yang memungkinkan pengguna bisa memasukkan nama kota untuk melihat informasi suhu atau cuaca. Terakhir, Motivasi Harian menampilkan kata-kata motivasi harian yang dapat diubah menggunakan tombol Ganti Motivasi.
